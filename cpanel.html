Conexión con Apps Script

Instalación rápida

  1. Crea un Google Sheets nuevo.
  2. Abre Extensiones → Apps Script.
  3. Pega el archivo apps_script/Code.gs.
  4. Coloca el ID de tu Google Sheets en la variable SPREADSHEET_ID.
  5. Ejecuta setup().
  6. Publica como Web App y pega la URL `/exec` aquí.

El archivo Excel `base_datos/estructura_hojas.xlsx` contiene la estructura de hojas sugerida.
